## Подпись

Релизные сборки до момента подписи выпускаются с отладочным ключом (config в `app/build.gradle.kts` читает `keystore.*` из `local.properties`). Для боевой подписи Сергею нужно заполнить в `local.properties`:

```
keystore.file=C:/path/to/keystore.jks
keystore.password=...
keystore.alias=...
keystore.keyPassword=...
```

и пересобрать `assembleRelease`.

# Базовая линия размера APK

Замер от 25.10.2026, скелет этапа 0–1 (Compose-заглушка, один экран, без источников данных).

| Вариант | Размер |
|---|---|
| `:app:assembleDebug` (без обфускации, с tooling) | 9 217 КБ (~9.0 МБ) |
| `:app:assembleRelease` (R8 full mode + resource shrinking, debug-подпись) | **668 КБ (~0.65 МБ)** |

Инструменты: Gradle 8.10.2, AGP 8.7.3, Kotlin 2.0.21, compileSdk 35, minSdk 26.

Смысл базовой линии: рост размера на каждом следующем этапе сравнивается с этим значением.
Ориентир финала — universal release ≤ 5 МБ (решение от 25.10.2026: скорость важнее размера,
жёсткого лимита нет). Замер повторяется на этапах 4–8 и пишется в `docs/size-report.md`.

# Дизайн-спека (по референсам: 6 скриншотов + скринкаст)

Источник значений — скриншоты 900×2000 px (плотность ~2.5–2.75×, т.е. ~340–360 dp ширины) и кадры видео. Все числа — «на глаз» по пикселям; на этапе 4 сверяем с референсом и правим ±1–2 dp. Светлая тема в скриншотах не заснята (только опция в настройках) — палитра выведена по аналогии, помечено.

## 1. Палитра

| Токен | Тёмная (по скриншотам) | Светлая (выведена) |
|---|---|---|
| Фон приложения | `#0D0F12` (почти чёрный) | `#F5F7FA` |
| Поверхность карточки | `#1C1F24` (строки прогноза), `#191C1F` (баннер карты) | `#FFFFFF` с тенью 0/1dp |
| Шапка, градиент дня | `#1E7BD6 → #1560BF` (яркий синий) | тот же |
| Шапка, градиент ночи | `#0B1626 → #0A101C` (тёмно-синий) | — |
| Акцент (Сегодня, выходные, выбранные сегменты) | `#FF5A2F`, градиент кнопок `#FF7A45 → #FF5A2F` | тот же |
| Текст основной | `#FFFFFF` | `#14181D` |
| Текст вторичный | белый 55 % | чёрный 55 % |
| Разделители | белый 5 % | чёрный 6 % |

Правило: акцент — только для «сегодня/выходные/выбранное/CTA». Больше нигде оранжевого нет.

## 2. Типографика

Шрифт референса — Yandex Sans (проприетарный, в APK лежит в `res/font`). Заменяем на системный sans (Roboto) с сохранением шкалы и весов; при желании позже — Inter (OFL).

| Стиль | Размер/вес | Где |
|---|---|---|
| display (температура героя) | 76 sp, Light | главный экран |
| title | 22 sp, Bold | «Прогноз на 10 дней», заголовки экранов |
| section-label | 13 sp, Regular, CAPS, 45 % | «Единицы измерения», «Тема оформления» |
| body | 17 sp, Regular | строки настроек, дни недели |
| secondary | 15 sp, Regular, 55 % | «район Отрадное», даты, «Ощущается как» |
| value | 18 sp, Medium | температуры дня/ночи, метрики |
| caption | 13–14 sp | подписи часов, единицы |

## 3. Сетка и формы

- Поля экрана: 16 dp; между карточками 8–12 dp; между секциями 24 dp.
- Радиусы: карточки 16 dp, кнопки-pill 24 dp, сегменты 8 dp, точки карусели 6 dp.
- Высота строки прогноза 84–88 dp; почасовой чип ~96 dp; карточка карты ~200 dp (в потоке главного экрана), полноэкранный вариант — отдельный экран.

## 4. Экраны

### Главный
- **Шапка** (на градиенте дня/ночи): по центру «Город» 20 sp semibold + строка «район» 15 sp 70 %; слева гамбургер (меню городов), справа шестерёнка. Высота ~56 dp + статус-бар.
- **Герой**: температура 76 sp Light; иконка 64 dp справа от цифры; строка состояния 18 sp; «Ощущается как: X°» 15 sp 75 %.
- **Метрики** (колонка слева, 16 sp, иконки 18 dp, межстрочный ~26 dp): ветер «3 м/с, ЮВ ◢», давление «759 мм рт. ст.», влажность «67 %», температура воды «6°» (волна; только для прибрежных).
- **Часы** (LazyRow справа от метрик): «сейчас» + часы, 14 sp 80 %; иконка 32 dp; температура 16 sp semibold; ночные — лунные иконки; разделитель суток (как «00:00 окт.» в референсе).
- **Карточка карты** (карусель 3 шт.): радиус 16 dp, поверх — плашка «В ближайшие 2 часа осадков не ожидается» (фон #191C1F 90 %, текст 16 sp, шеврон), ниже — плашка-CTA «Показать на карте» (pill, градиент акцента). Точки-индикатор 6 dp под карточкой.
- **Список 10 дней**: заголовок 22 sp Bold; строка — карточка #1C1F24, радиус 16 dp: слева дата 14 sp 55 % + день 17 sp (для «Сегодня/Завтра» — акцент), по центру иконка 28 dp, справа две колонки «День/Ночь» (метка 13 sp 55 %, значение 18 sp). Выходные — акцент.
- **Нижние блоки**: «Погода на карте» (заголовок + мини-карта + CTA), «Прогноз на месяц» (surface-кнопка, v2), атрибуция «Данные: Яндекс Погода (Meteum)» 12 sp 45 %.

### Карта
- Полноэкранный рендер (тёмная база), чип выбора слоя сверху справа: иконка + «Осадки ▾», фон #1C1F24 90 %, pill.
- Таймлайн снизу: метки времени 14 sp, красный указатель «Сейчас», проигрывание кадров по тапу.
- Пин города 40 dp, нижняя полупрозрачная панель — без краудсорса (у нас его нет).

### Города
- Список как в настройках: строки 56 dp, справа «⋮» для удаления; поиск сверху (поисковая строка 48 dp, радиус 24 dp); «Моё местоположение» первой строкой.

### Настройки
- Шапка: стрелка-назад (акцент) + заголовок 20 sp.
- Секции с метками CAPS 13 sp 45 %, строки 56–64 dp, разделители 5 %.
- Сегментированные переключатели (°C/°F, м/с|км/ч, мм рт.ст.|гПа): выбранный — заливка градиентом акцента, белый текст; невыбранный — прозрачный, обводка 40 %, текст 55 %.
- Тема — радио-строки (3), выбранное — акцентное кольцо.
- Геолокация — Switch; «Место» — строка с шевроном и подписью «Текущее место».
- Виджеты — подсекция с тремя строками и мини-превью; «Уведомления» — переход.

### Настройка виджета
- Превью наверху (фон — фото с настраиваемой прозрачностью): часы 44 sp Light, дата+город 15 sp, справа иконка+температура 40 sp, «Днём/Ночью» 13 sp.
- Строки: ч/б иконки (Switch), светлый фон (Switch), прозрачность (Slider с подписями «Непрозрачно/Прозрачно»), место.

## 5. Виджеты и уведомления (обязательный объём MVP)

### 5.1 Домашний виджет — два размера

**2×2 «Малый»** (~110×110 dp, minWidth/minHeight 110 dp):
```
┌────────────────┐
│ 10:42      ☀   │  часы 22 sp Light, иконка 28 dp
│            +7° │  температура 34 sp Light
│ Москва         │  13 sp 70 %
└────────────────┘
```

**4×2 «Большой»** (~250×110 dp):
```
┌─────────────────────────────────────┐
│ 10:42                    ☀   +7°   │  часы 22 sp, иконка 32 dp, темп 34 sp
│ ВС, 25 окт · Москва                │  13 sp 70 %
│ Ясно · Днём +11° · Ночью +4°       │  12 sp 70 %
└─────────────────────────────────────┘
```

- Фон: полупрозрачный тёмный (alpha настраивается 0–100 %) либо светлый (опция «светлый фон»), иконки — цветные или ч/б (опция).
- Тап по виджету — открыть MainActivity на этом городе; тап по часам/дате — ничего.
- Контент: только текущая погода (без списков) — RemoteViews не умеет Lazy-списки.
- Обновление: WorkManager каждые 30–60 мин (те же данные, что для уведомлений); `updatePeriodMillis` не используем (системный минимум 30 мин и непредсказуем) — AlarmManager/WorkManager надёжнее.

### 5.2 Виджет в шторке (ongoing-уведомление)

```
┌──────────────────────────────────────┐
│ [иконка погоды 24 dp]  +7°           │
│ Ощущается как: +3°                   │
│ Ветер 3 м/с, ЮВ · Москва             │
└──────────────────────────────────────┘
```
- Это постоянное (ongoing) уведомление с `setOnlyAlertOnce(true)`, без звука/вибрации при обновлении; сворачивается системой в одну строку.
- Канал `weather_shade`, IMPORTANCE_LOW, без бейджа; тап — открыть приложение.
- Обновляется тем же WorkManager-циклом; при ошибке сети — остаётся последнее значение + «(обновлено 12:30)».

### 5.3 Уведомление «Погода на сегодня»

```
Погода на сегодня · Москва            10:32
+5…+11° · Ясно, без осадков · Слабый ветер
3–4 м/с, порывы до 9 м/с
```
- Отдельный канал `weather_daily`, IMPORTANCE_DEFAULT;
- Отправка раз в день в 08:00 (настраиваемое время в v2; в MVP — фиксированно 08:00 локального времени), не чаще;
- Большая иконка (condition 64 dp), тап — главный экран.
- При отсутствии разрешения POST_NOTIFICATIONS (Android 13+) — запрос при первом запуске, отказ не ломает приложение (пункт «Уведомления» в настройках ведёт на системные настройки).

### 5.4 Общие правила
- Все тексты виджетов/уведомлений — те же форматтеры единиц, что и в приложении (°C/°F и т.д. из настроек).
- Состояния: данные есть / кэш устарел (>2 ч — показываем с пометкой) / нет данных (виджет показывает «—» и «нет данных»).
- RemoteViews-ограничения: только статические вьюхи, поэтому анатомия виджетов фиксированная, без анимаций.

## 6. Иконки погоды

Набор ~20 состояний (MVP — 14): ясно (д/н), малооблачно (д/н), облачно с прояснениями (д/н), пасмурно, дождь, ливень, гроза, снег, снег с дождём, град, туман, дымка. Стиль: заливные, двухцветные (белое облако + жёлтое солнце / белая луна), 24–64 dp; векторные (`res/drawable`), генерируются из одного шаблона на этапе 4.

## 7. Тексты состояний (словарь)

«Ясно», «Малооблачно», «Облачно с прояснениями», «Пасмурно», «Дождь», «Ливень», «Гроза», «Снег», «Снегопад», «Дождь со снегом», «Град», «Туман», «Дымка», «Пыль». Формулы: «Ощущается как: X°», «В ближайшие 2 часа осадков не ожидается», «Погода на сегодня · {город}».

## 8. Маппинг на Compose (этап 4)

- `MaterialTheme.colorScheme`: background/surface/primary — из палитры; `Typography` — переопределения шкалы (displayLarge = 76 sp Light и т.д.); `Shapes` (medium 16 dp, large 24 dp).
- Компоненты-скелеты: `CurrentWeatherBlock`, `MetricRow`, `HourlyStrip`, `MapPreviewCard`, `DayForecastRow`, `SectionHeader`, `SegmentedControl`, `SettingsRow`, `SwitchRow`, `SliderRow`, `RadioRow`.
- Тёмная/светлая — `isSystemInDarkTheme()` + переключатель в настройках (тема из DataStore/SharedPreferences применяется на старте).
- Анимации: только композерные дефолты; без кастомных эффектов (скорость).

## 9. Отличия от референса (осознанные)

1. Шрифт — системный вместо Yandex Sans.
2. Нет рекламных блоков, краудсорса («У вас идет дождь?»), скинов зонтов.
3. «Прогноз на месяц» — отложен (v2), не входит в MVP.
4. Светлая тема — производная палитра (в скриншотах не заснята).

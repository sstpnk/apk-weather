# План работ v2 (решения от 25.10.2026 внесены)

Основание: `docs/01-research.md`, `docs/02-architecture.md`. Репозиторий: https://github.com/sstpnk/apk-weather (push настроен, токен через git credential manager).

## Правила движения

- Каждый этап закрывается проверкой: `assembleDebug` + `testDebugUnitTest` (+`assembleRelease` где уместно), замер APK, для UI — смок на устройстве.
- Тесты — на фикстурах из HAR/спайков (реальные ответы источников).
- Системные установки — только с разрешения Сергея (SDK уже установлен — ок).
- Этап 2 может использовать REA (`rea` CLI, headless JADX + JDK 17) для извлечения GraphQL-схем из APK.

## Этапы

### Этап 0–1. Инфраструктура и скелет — выполняется сейчас
- Готово: Gradle 8.10.2 + AGP 8.7.3 + Kotlin 2.0.21, Compose-скелет (MainActivity, тема, иконка), CI (`android-ci.yml`), README, `.gitignore` (референсы/анализ не публикуются), `local.properties` с SDK.
- Проверка: первая сборка `:app:assembleDebug` зелёная, размер зафиксирован как база, push в main прошёл, CI зелёный.

### Этап 2. Спайки источников
1. **Yandex GraphQL**: подобрать запросы `fact/hourly/daily/location` по шаблонам из HAR; при пробелах — декомпиляция `ru.yandex.weatherplugin.apk` через REA (Apollo-схемы в коде). Проверить заголовки (UA/origin) с ПК.
2. **Nowcast-тайл**: формат `new_encoded_tile` (бинарный); если не расшифровывается за разумное время — баннер из почасовых полей.
3. **Raster-maps raw-tile**: формат слоёв температуры/ветра/давления/снега.
4. **Open-Meteo geocoding**: смок поиска «Москва»/«СПб» на ru.
- Выход: зафиксированные запросы, фикстуры ответов в `app/src/test/resources/fixtures/`, вывод спайк-скрипта (JVM) с домен-моделью для Москвы и СПб.

### Этап 3. Слой данных
- Домен-модели; `YandexSource` (GraphQL DTO, nowcast); Open-Meteo геокодер; `WeatherRepository` (кэш, TTL, деградация); форматтеры единиц.
- Проверка: unit-тесты на фикстурах (парсинг, fallback, единицы), прогон репозитория на живых данных, отчёт покрытия.

### Этап 4. Главный экран (Compose)
- Шапка, блок «сейчас», почасовая лента (LazyRow), список 10 дней (LazyColumn), карточка осадков, pull-to-refresh, состояния загрузка/ошибка/кэш.
- Проверка: смок на устройстве, сравнение с референсом, замер APK.

### Этап 5. Карта погоды
- osmdroid + растровые тайлы OSM, слои Яндекса по итогам спайка, таймлайн −2…+2 ч, пин города.
- Проверка: смок (зум/скролл/анимация), LRU-кэш тайлов, отсутствие фризов.

### Этап 6. Города, геолокация, настройки
- Список/поиск городов (Open-Meteo), LocationManager + разрешения, настройки: единицы, тема, интервал обновления.
- Проверка: смок сценариев, тесты форматтеров, смена темы.

### Этап 7. Виджеты и уведомления
- Малый и большой виджеты (RemoteViews), периодическое обновление WorkManager, ежедневное уведомление «Погода на сегодня», виджет в шторке.
- Проверка: виджеты на реальном лаунчере, уведомления после перезагрузки, замер APK.

### Этап 8. Харденинг и релиз
- R8 full mode, resource shrinking, удаление неиспользуемого, отчёт размера `docs/size-report.md` (ориентир ≤ 5 МБ universal).
- Подпись: keystore Сергея → `local.properties` (`keystore.*`), GitHub Release с APK/AAB.
- Проверка: финальный прогон тестов/CI, установка release на устройство, чек-лист функций референса.

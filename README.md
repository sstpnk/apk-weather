# apk-weather — минимальное приложение погоды для Android

Личное приложение погоды по мотивам Яндекс Погоды: текущая погода, почасовой прогноз,
прогноз на 10 дней, карта, города с геолокацией, настройки единиц и темы, два виджета
и уведомления. Один источник данных — веб-страницы pogoda.yandex.ru (RSC-парсинг),
резерв — api.met.no.

> Приоритет проекта: **скорость разработки важнее размера APK** (при этом release —
> ~1.6 МБ, ориентир ≤ 5 МБ).

## Возможности

- Текущая погода: температура, ощущается, вода, ветер (СВ/ЮВ…), давление, влажность, УФ.
- Почасовая лента и прогноз на 10 дней с частями суток.
- Баннер осадков на ближайшие 2 часа (по сводкам).
- Карта города (OSM), пин.
- Несколько городов: поиск (Open-Meteo geocoding), «Моё местоположение» (LocationManager).
- Единицы: °C/°F, м/с|км/ч, мм рт. ст.|гПа; темы светлая/тёмная/системная.
- Виджеты 2×2 (часы, погода) и 4×2 (часы, дата, сводка), обновление WorkManager раз в час.
- Уведомление-виджет в шторке (тихое, ongoing) и ежедневный прогноз в 08:00.

## Сборка

Требуется JDK 17 и Android SDK (platform 35, build-tools 35.x). Путь к SDK — в
`local.properties` (`sdk.dir=...`), файл в git не входит.

```bash
./gradlew :app:assembleDebug        # отладочная сборка
./gradlew :app:assembleRelease      # релизная (R8; подпись — см. local.properties)
./gradlew :app:testDebugUnitTest    # тесты
./gradlew :app:lintDebug            # lint
```

Приложение: `tech.stpnk.weather`, minSdk 26, targetSdk 35.

## Источник данных и правовая заметка

Данные — публичная веб-страница Яндекс Погоды (используется их собственным веб-клиентом);
официальный API для сторонних разработчиков платный (см. `docs/01-research.md`). Проект
персональный, не для распространения в магазинах; запросы единичные (кэш 30–60 мин,
обновление виджетов раз в час). Атрибуция: данные предоставлены Яндекс Погодой (Meteum).
Резервный источник — api.met.no (MET Norway, свободный доступ).

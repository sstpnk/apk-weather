# apk-weather — минимальное приложение погоды для Android

Личное приложение погоды по мотивам Яндекс Погоды: текущая погода, почасовой прогноз,
прогноз на 10 дней, карта с осадками, виджеты и уведомления. Один источник данных —
веб-API Яндекс Погоды (`api.weather.yandex.ru`), интерфейс — Jetpack Compose.

> Приоритет проекта: **скорость разработки важнее размера APK** (размер всё равно
> контролируем — ориентир ≤ 5 МБ universal release).

## Сборка

Требуется JDK 17 и Android SDK (platform 35, build-tools 35.x). Путь к SDK — в
`local.properties` (`sdk.dir=...`), файл в git не входит.

```bash
./gradlew :app:assembleDebug        # отладочная сборка
./gradlew :app:assembleRelease      # релизная (R8, подпись — см. local.properties)
./gradlew :app:testDebugUnitTest    # тесты
```

Приложение: `tech.stpnk.weather`, minSdk 26, targetSdk 35.

## Источник данных и правовая заметка

Данные — публичный веб-эндпоинт Яндекс Погоды, используемый их собственным веб-клиентом;
официальный API для сторонних разработчиков платный (см. `docs/01-research.md`). Проект
персональный, не для распространения в магазинах; запросы кэшируются и ограничены по
частоте. Атрибуция: данные предоставлены Яндекс Погодой (Meteum).

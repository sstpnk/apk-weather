# apk-weather

Минималистичное приложение погоды для Android. Показывает прогноз Яндекс Погоды,
карту с радаром осадков, домашние виджеты и настраиваемые уведомления.

## Возможности

- Текущая погода: температура и «ощущается как», ветер, давление, влажность,
  УФ-индекс, видимость и температура воды, когда она доступна.
- Почасовой прогноз, прогноз на 10 дней, восход и закат, предупреждения и
  оценка вероятности осадков в ближайшие часы.
- Несколько городов: поиск, определение текущего местоположения и быстрое
  переключение между сохранёнными городами.
- Интерактивная карта Яндекс Погоды с радаром осадков для выбранного города.
- Светлая, тёмная и системная тема; °C/°F, м/с или км/ч, мм рт. ст. или гПа.
- Виджеты 2×1, 2×2 и 4×1 с настройкой прозрачности, монохромных иконок и
  частоты обновления.
- Постоянная карточка погоды в шторке и отдельные уведомления утром и вечером.

## Источники погоды

В настройках можно выбрать [Яндекс Погоду](https://yandex.ru/pogoda/) или
[Open-Meteo](https://open-meteo.com/). Оба источника доступны без API-ключа.
При временной ошибке показывается последний сохранённый прогноз выбранного
источника; автоматической смены источника нет.

Карта с радаром доступна при выборе Яндекс Погоды.

## Установка и сборка

Для сборки из исходников нужны JDK 17 и Android SDK Platform 35. Укажите путь к SDK
в `local.properties`:

```properties
sdk.dir=/path/to/Android/Sdk
```

Соберите релизный APK:

```bash
./gradlew :app:assembleRelease
```

Готовый файл появится в `app/build/outputs/apk/release/`. Чтобы подписать релиз
своим ключом, добавьте в `local.properties` параметры `keystore.file`,
`keystore.password`, `keystore.alias` и `keystore.keyPassword`.

Идентификатор приложения — `tech.stpnk.weather`; минимальная версия Android — 8.0
(API 26).
